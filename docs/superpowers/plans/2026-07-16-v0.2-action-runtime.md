# Seed Society v0.2 Action Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real-model role adapters, linked execution traces, policy-controlled tools, durable approval pauses, and a safe GitHub issue maintenance intake workflow.

**Architecture:** Keep `LoopEngine` as the lifecycle owner and add focused modules around it. Domain and storage own durable contracts; `TraceRecorder` owns span timing; `ToolExecutor` owns policy and approval enforcement; model adapters translate strict JSON into existing planner, worker, and reviewer protocols; maintenance wiring composes those pieces without granting repository mutation by default.

**Tech Stack:** Python 3.10+ standard library, SQLite, `urllib`, `subprocess` only for future approved tools, `unittest`.

## Global Constraints

- Preserve all v0.1 CLI commands and deterministic behavior.
- Add no mandatory third-party dependency.
- Persist no API keys, authorization headers, or unredacted secrets.
- Read tools may execute without approval; write and execute tools require durable approval.
- Pending approval pauses a goal without recording an attempt or consuming action budget.
- The initial `maintain` command is read-only and produces a reviewed proposal, not an applied patch or pull request.
- Every production behavior is introduced by a failing test first.
