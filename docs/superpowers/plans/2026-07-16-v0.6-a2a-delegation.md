# Agent Society Loop v0.6 A2A Delegation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add fail-closed A2A 1.0 HTTP+JSON remote specialists that remain governed by local review, budgets, benchmark evidence, explicit promotion, and durable audit state.

**Architecture:** A zero-dependency `a2a.py` module owns card validation, bounded HTTP, registration, delegation, polling, cancellation, remote workers, and benchmark runners. Typed records live in `domain.py`, SQLite owns durable state, and `LoopEngine` excludes remote profiles until an exact deployment is active. CLI composition opts into network execution explicitly.

**Tech Stack:** Python 3.10+, standard-library `urllib`, `sqlite3`, `ThreadingHTTPServer`, `unittest`, existing Agent Society domain/engine/tracing APIs.

## Global Constraints

- Support only A2A `1.0` `HTTP+JSON` using `SendMessage`, `GetTask`, and `CancelTask` polling.
- Preserve zero runtime dependencies and Python 3.10-3.14 support.
- Never follow redirects, downgrade protocol versions, or resend an ambiguous Send Message.
- Require operator-pinned card SHA-256, interface URL, skill map, and auth environment variable name.
- Allow plain HTTP only for explicit loopback development registrations.
- Exclude A2A profiles from routing until an exact promoted deployment is active.
- Keep local review, global action budget, remote request/poll/deadline limits, tracing, and SQLite evidence.
- Do not persist or print bearer values, private HTTP bodies, or unredacted sensitive fields.

@dataclass(frozen=True, slots=True)
class A2ALimits:
    request_timeout: float = 10.0
    total_timeout: float = 60.0
    max_request_bytes: int = 131_072
    max_response_bytes: int = 1_048_576
    max_result_bytes: int = 262_144
    max_polls: int = 20
    poll_interval: float = 0.25

class A2AHTTPClient:
    def inspect_card(self, card_url: str) -> AgentCardInspection:
        body, headers = self._request("GET", card_url, None, ambiguous=False)
        return AgentCardInspection.parse(body, headers)

    def send_message(self, interface_url: str, payload: dict[str, Any]) -> dict[str, Any]:
        return self._json_request("POST", f"{interface_url.rstrip('/')}/message:send", payload, ambiguous=True)

    def get_task(self, interface_url: str, task_id: str) -> dict[str, Any]:
        encoded = urllib.parse.quote(task_id, safe="")
        return self._json_request("GET", f"{interface_url.rstrip('/')}/tasks/{encoded}", None, ambiguous=False)

    def cancel_task(self, interface_url: str, task_id: str) -> dict[str, Any]:
        encoded = urllib.parse.quote(task_id, safe="")
        return self._json_request("POST", f"{interface_url.rstrip('/')}/tasks/{encoded}:cancel", {}, ambiguous=False)
```

Use a redirect-rejecting `HTTPRedirectHandler`, default TLS verification,
`A2A-Version: 1.0`, media type checks, bounded reads, canonical JSON requests,
and sanitized `A2AHTTPError`/`A2AAmbiguousSubmission` categories.

class A2ARemoteExecutor:
    def delegate(self, task: Task, context: dict[str, Any]) -> RemoteExecution:
        attempt_no = len(self.repository.list_reviews(task.goal_id, task.task_id)) + 1
        existing = self.repository.get_attempt_delegation(
            task.goal_id, task.task_id, attempt_no, self.registration.agent_id
        )
        return self._resume(existing) if existing is not None else self._submit(task, context, attempt_no)

    def cancel(self, delegation_id: str, decided_by: str) -> DelegationRecord:
        delegation = self.repository.get_delegation(delegation_id)
        if delegation is None:
            raise KeyError(f"delegation not found: {delegation_id}")
        return self._cancel_known_task(delegation, decided_by)
```

Persist `PREPARED` and `SUBMITTING` before POST. Never resend `SUBMITTING` or
`UNKNOWN`. Resume `ACCEPTED` by GET and `COMPLETED` from persisted content. Use
one best-effort cancel on deadline. Emit `a2a.card`, `a2a.send`, `a2a.get`, and
`a2a.cancel` spans with redacted bounded attributes.
