# Agent Society Loop v0.3 Guarded Execution Implementation Plan

## Goal

Deliver a durable local repository mutation loop without introducing arbitrary
shell execution or remote Git side effects.

## 1. Persistence contracts

- Add immutable workspace snapshot and verification result domain records.
- Add SQLite tables and repository methods for create/read/update/list.
- Prove records survive reopen and updates are goal/path scoped.
- Prove snapshot originals are never overwritten by later writes.

Verification: focused domain and storage tests.

## 2. Content-addressed workspace writes

- Extend file reads with SHA-256.
- Centralize protected-path and symlink checks.
- Add atomic UTF-8 replacement with expected hash validation.
- Persist original snapshots and latest written hashes through contextual tool
  invocation.
- Add durable idempotent restore with external-change conflict protection.

Verification: temporary Git workspaces, stale hash, path escape, symlink,
restart, repeated write, restore, and conflict tests.

## 3. Fixed verification checks

- Add Git status/diff inspection and deterministic workspace digest.
- Add named check configuration and shell-free execution.
- Bound runtime and output; normalize timeout as a failed result.
- Persist every result against goal, task, check, and workspace digest.

Verification: passing, failing, timeout, unknown check, output limit, and proof
that model arguments cannot alter the command.

## 4. Guarded maintenance composition

- Add optional guarded tools to the maintenance engine.
- Require a clean Git worktree before creating an apply-mode run.
- Add `--apply` and repeatable `--check NAME=COMMAND` CLI options with a strict
  command parser.
- Preserve read-only defaults and existing command output.
- Update apply-mode goal evidence and required final sections.

Verification: scripted provider integration pauses/resumes across write and
check approvals, repairs a failed check, passes review, and leaves an inspectable
diff plus durable evidence.

## 5. Documentation and release

- Update architecture, English/Chinese READMEs, CLI help, changelog, and version.
- Run the full suite, compileall, build, wheel install/smoke test, diff check, and
  sensitive-token scan.
- Review safety boundaries, open a PR, require the Python matrix, merge, tag, and
  publish v0.3.0 artifacts.
