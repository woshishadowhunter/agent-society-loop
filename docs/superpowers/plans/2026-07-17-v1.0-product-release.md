# v1.0 Product Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Agent Society Loop as a v1.0 product release with a single install-time readiness check, stable-version metadata, and operator-facing production handoff documentation.

**Architecture:** Keep the v0.10 runtime behavior intact and add a narrow product readiness layer that composes existing deterministic demo, scheduler self-test, A2A reliability self-test, package version check, and documentation presence checks. The release remains standard-library Python with optional PostgreSQL support.

**Tech Stack:** Python 3.10+, unittest, argparse CLI, SQLite, existing package metadata, Markdown docs.

## Global Constraints

- Do not add third-party runtime dependencies.
- Do not weaken existing fail-closed remote, approval, scheduler, model, or publication boundaries.
- Maintain Python 3.10 through 3.14 compatibility.
- Use TDD for new behavior.
- Keep v1.0 scope productization-focused; no speculative agent features.

- Produces CLI: `agent-society product self-test --json`

- [ ] **Step 1: Write failing readiness tests**

Add tests covering a passing report, missing documentation failure, and CLI JSON output:

```python
import json
import subprocess
import sys
import unittest

from agent_society_loop.readiness import run_product_readiness_self_test


class ProductReadinessTests(unittest.TestCase):
    def test_product_readiness_report_passes_with_required_checks(self):
        report = run_product_readiness_self_test("1.0.0")

        self.assertTrue(report["passed"])
        self.assertEqual(report["version"], "1.0.0")
        self.assertEqual(
            [check["name"] for check in report["checks"]],
            [
                "version",
                "docs",
                "deterministic_demo",
                "scheduler_self_test",
                "a2a_reliability_self_test",
            ],
        )
        self.assertTrue(all(check["passed"] for check in report["checks"]))

    def test_product_readiness_fails_when_required_doc_is_missing(self):
        report = run_product_readiness_self_test(
            "1.0.0", required_docs=("docs/does-not-exist.md",)
        )

        self.assertFalse(report["passed"])
        docs = next(check for check in report["checks"] if check["name"] == "docs")
        self.assertFalse(docs["passed"])
        self.assertIn("docs/does-not-exist.md", docs["details"]["missing"])

    def test_product_self_test_cli_emits_json(self):
        completed = subprocess.run(
            [sys.executable, "-m", "agent_society_loop.cli", "product", "self-test", "--json"],
            check=True,
            capture_output=True,
            text=True,
        )

        report = json.loads(completed.stdout)
        self.assertTrue(report["passed"])
        self.assertEqual(report["version"], "1.0.0")
```
