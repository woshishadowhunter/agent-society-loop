# Agent Society Loop v0.7 Delegation Trust Control Plane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Require content-addressed operator policy and fresh official A2A TCK evidence before new production remote delegations, with durable decisions, readiness diagnostics, and a local reliability campaign.

**Architecture:** New immutable records live in `domain.py` and SQLite. A focused `a2a_governance.py` module parses strict policy/TCK documents, evaluates decisions, and builds doctor reports; `a2a_reliability.py` exercises executor invariants without network access. The existing A2A executor consumes an optional policy evaluator, while CLI production composition requires it.

**Tech Stack:** Python 3.10+, standard-library JSON/hash/date APIs, SQLite, urllib, unittest, official A2A TCK 1.0 compatibility JSON schema.

## Global Constraints

- Preserve zero runtime dependencies and Python 3.10-3.14 support.
- Do not execute TCK, Inspector, ITK, shell, or model-provided policy code.
- Production CLI sends require exact deployment, active policy, valid required attestation, and `--allow-remote`.
- Default policy is always DENY; no wildcards, arbitrary expressions, callbacks, fallback, resend, or auto-activation.
- Persist a policy decision before creating a new delegation or performing network I/O.
- Existing accepted/completed v0.6 delegations remain resumable with their stored authority.
- Never persist bearer values, report URLs containing credentials, private bodies, or model-provided executable text.
