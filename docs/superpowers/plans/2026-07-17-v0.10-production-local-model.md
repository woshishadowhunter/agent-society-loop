# v0.10 Production Local Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make local OpenAI-compatible models deployable as durable workers and close the highest-risk production gaps around lease time, side-effect delivery, health, and packaging.

**Architecture:** Add a strict JSON runtime configuration that builds model-backed workers and an independent reviewer without storing secrets. Keep the current scheduler contracts, but source production worker timestamps from the selected database. Add a durable transactional outbox as an explicit boundary for integrations, plus bounded health and metrics commands used by a dependency-free container deployment.

**Tech Stack:** Python 3.10+, standard library HTTP and JSON, SQLite, optional PostgreSQL/psycopg 3, unittest, Docker Compose.

**Status:** Implemented and verified on 2026-07-17; PostgreSQL 17 and container execution remain CI release gates.

## Global Constraints

- Preserve deterministic specification workers and all existing CLI behavior.
- Keep secrets in environment variables and redact provider errors.
- Require explicit task types and one configured owner per task type.
- Permit unauthenticated model endpoints only on loopback addresses.
- Keep SQLite scheduler support limited to one host and PostgreSQL for multi-host execution.
- Do not add a web control plane, message broker, or model-server dependency.
- Every production-code behavior starts with a failing unittest.
